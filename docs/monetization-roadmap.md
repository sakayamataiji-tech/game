# ブロックル 収益化ロードマップ

「作る → 公開 → 拡散を検証 → ポータルで広告収益 → 伸びたらアプリ化」の順で進める。
各フェーズに**進む/止まる判断基準**を置き、数字が出ないうちに次の投資（ドメイン・アプリ化・課金）をしない。

## 全体像

| フェーズ | 期間の目安 | ゴール | 費用 |
|---|---|---|---|
| 0. 公開準備 | 今週 | Pages で公開、計測が動く | 0円 |
| 1. 拡散検証 | 公開後 2 週間 | シェア率・翌日戻り率を測る | 0円 |
| 2. ポータル投稿 | 2〜6 週目 | CrazyGames / Poki で**初めての広告収益** | 0円 |
| 3. リテンションと広告最適化 | 6〜12 週目 | 収益を「日課」で積み上げる | 0円 |
| 4. 自社ドメイン + AdSense（任意） | 3 か月目〜 | ポータル外の収益源 | 年 1,500 円前後 |
| 5. アプリ化（AdMob + 広告削除課金） | Web で数字が出てから | ストア収益、課金 | Apple 年 99 ドル、Google 一回 25 ドル |

---

## フェーズ 0：公開準備（今週）

**やること**

1. ブランチを `main` にマージし、Settings → Pages → Source を「GitHub Actions」にする。
2. 公開 URL（`https://sakayamataiji-tech.github.io/game/`）でスマホ実機（iOS Safari / Android Chrome）で遊んで、ドラッグと回転の操作感を確認する。
3. 計測を接続する。GA4 のタグを `index.html` に入れるだけで `track()` が送信を始める。見る指標は下記 4 つ。
4. OGP 画像（1200×630）を用意して X でリンクが綺麗に展開されるようにする。
5. プライバシーポリシーページを追加する（ポータルと AdMob の両方で必須になる）。
6. シェア文の URL を公開 URL にする。

**この段階で見る指標**

| 指標 | 定義 | 目安 |
|---|---|---|
| 開始率 | `puzzle_start` / ページ表示 | 70% 以上（低ければ最初の画面が重い） |
| クリア率 | `puzzle_solved` / `puzzle_start` | 50〜70%（低すぎれば難しすぎ） |
| シェア率 | `share` / `puzzle_solved` | **10% 以上が合格ライン** |
| 翌日戻り率 | 翌日も `puzzle_start` した人の割合 | **20% 以上が合格ライン** |

---

## フェーズ 1：拡散検証（公開後 2 週間）

広告費はかけない。「シェアされるか」「翌日戻ってくるか」だけを確かめる。

**やること**

1. 自分のアカウントで毎日クリア結果（絵文字グリッド）を X に投稿する。同じ時間帯に固定する。
2. 投稿先を 5 か所ほど試す：X、個人開発コミュニティ（Zenn / note の開発記事）、Reddit（r/WebGames、r/incremental_games ではなく r/puzzles 系）、itch.io（HTML5 で投稿可、無料）、Discord のパズル系サーバー。
3. 日ごとに「どこから来た人が翌日戻ったか」を GA4 の流入元で見る。

**判断**

- シェア率 10% 以上 **または** 翌日戻り率 20% 以上 → フェーズ 2 へ。
- どちらも届かない → ゲーム側を直す。優先順位は (1) 難易度（初日は 5×5 にする等）、(2) シェア文の見た目、(3) クリア演出。2 週間ごとに 1 つ変えて再測定する。
- 2 回直しても届かない → このゲームは「2 本目」の素材にして、別ジャンルで 1 本目をやり直す（3 本作って 1 本当てる前提）。

## フェーズ 2：ポータル投稿で初収益（2〜6 週目）

自前サイトで広告を貼るより、既に月 5,000 万〜1 億人が来ているポータルに置くほうが早い。

### CrazyGames（先にやる）

- **Basic Launch** は SDK 不要で申請でき、まず掲載されるかを試せる。ただし収益化は **Full Launch** に選ばれてからで、その時点で SDK 組み込みが必須。
- 分配は広告収益の約 60%、課金は 70%。支払いは月次、100 ユーロから。
- 技術条件：初期ダウンロード 50MB 以下（モバイルのトップに載るには 20MB 以下）。ブロックルは約 1.3MB なので問題ない。
- 独占契約なし。Poki や自前サイトと並行できる。

### Poki（並行して申請）

- 人手でキュレーションされるので通りにくいが、通れば規模が大きい。
- 必要なもの：静止＋アニメーションのサムネイル、進行の保存（実装済み）、ゲーム内から開けるプライバシーポリシー、タブレットでモバイル操作系を強制、デバッグコード除去。
- 受理後に Poki SDK の組み込みが必須になる。

### 準備物（両方共通）

- 英語のタイトル・説明文・操作説明（英語 UI は実装済み）。
- サムネイル（正方形と横長）とプレイ動画（10〜20 秒）。
- 本リポジトリ側の作業：`VITE_PORTAL=poki|crazygames` でビルド時に SDK の script タグを差し込む仕組み。`src/services/ads.js` は SDK を自動検出するので、ゲーム側の変更は不要。

**判断**

- どちらかで Full Launch 相当になり広告収益が出始めたらフェーズ 3 へ。
- 掲載されない場合、フィードバックの多くは「見た目」と「最初の 30 秒」。チュートリアル 1 問（3×3）と効果音を足して再申請する。

## フェーズ 3：リテンションと広告最適化（6〜12 週目）

広告収益 ＝ DAU × 1 人あたり広告表示数 × 単価。単価はほぼ決められないので、**DAU と表示数を「日課」で伸ばす**。

**リワード広告の枠を増やす（ユーザーが自分で選ぶ広告は嫌われにくい）**

1. ヒント（実装済み）
2. 「昨日の問題をもう一度」（見逃した日を埋めて連続記録を守る）
3. エンドレスの追加問題セット
4. 週末の難問へのアクセス

**インタースティシャル**：エンドレス 3 問ごと（実装済み）。日替わりモードには入れない。日課を邪魔すると翌日戻り率が落ちる。

**リテンション機能**（優先順）

1. クリア履歴カレンダー（連続記録の可視化）
2. 難易度カーブ：月曜 5×5 → 金曜 6×6 → 週末 7×7
3. 実績（10 日連続、ノーヒント、1 分以内）
4. 友達とのタイム比較（URL に結果を埋め込むだけでサーバー不要）

**収益の目安（ブラウザ広告、要検証）**

| DAU | 1 人あたり表示 | 単価（1,000 表示あたり） | 月収の目安 |
|---|---|---|---|
| 1,000 | 3 回 | 150〜300 円 | 1.4〜2.7 万円 |
| 5,000 | 3 回 | 150〜300 円 | 7〜14 万円 |
| 20,000 | 4 回 | 150〜300 円 | 36〜72 万円 |

単価は地域とリワード比率で大きく動く（米国向けは高い、リワード広告は高い）。ポータル経由なら上記から分配率を掛ける。

## フェーズ 4：自社ドメイン + AdSense（任意、3 か月目〜）

- `github.io` のサブドメインは AdSense 審査に通りにくいため、やるなら独自ドメイン（年 1,500 円前後）を GitHub Pages に当てる。
- ゲーム 1 画面だけのサイトは審査で「コンテンツが薄い」と見なされやすい。「解き方」「今日の問題の解説」「過去問アーカイブ」など数ページのテキストを持たせる。
- ポータル収益が出ているなら後回しでよい。自社ドメインの主目的は**ブランドとシェア URL を自分の資産にすること**。

## フェーズ 5：アプリ化（Web で数字が出てから）

**進む条件**：Web で DAU 1,000 以上、または 7 日後継続率 10% 以上（パズル平均は 4.5%）。

**やること**

1. Capacitor でラップ（Phaser の Web ビルドをそのまま使える）。AdMob プラグインは capawesome または capacitor-community。
2. `src/services/ads.js` に `admob` プロバイダを追加（リワード・インタースティシャル・同意フロー UMP）。
3. 課金は **広告削除（買い切り 300〜500 円）** の 1 つだけから始める。ガチャや通貨は作らない。
4. ストア費用：Google Play 一回 25 ドル、Apple Developer 年 99 ドル。
5. ストア審査で必要：プライバシーポリシー URL、広告 ID の使用申告、スクリーンショット（iPhone / iPad / Android）。

---

## 事務・お金まわり（日本の個人の場合）

- ポータルからの支払いは海外送金が多い。Payoneer か Wise の口座を先に作っておく。
- 副業の場合、給与以外の所得が年 20 万円を超えたら確定申告（雑所得）。経費はドメイン・Apple 年会費・素材購入など。
- 広告 SDK を入れた時点で **プライバシーポリシーは必須**。フェーズ 0 で作っておく。
- 収益は最初の数か月は月数百〜数千円が普通。判断はお金ではなく上の指標（シェア率・戻り率・DAU）で行う。
